# Local Admin UI for Editing JSON

This small local admin tool lets you edit `gallery-data.json` and `site-data.json` visually and upload images into the `img/` folder.

Run locally:

```bash
npm install
npm start
# open http://localhost:3000/admin
```

Notes:
- Backups are created in the `backups/` folder before saving.
- This server writes files directly in the project — use locally only.
